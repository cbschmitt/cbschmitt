# Creative DNA

- **hero**: kinetic-canvas
- **nav**: minimal-line
- **cards**: catalog-tile
- **grid**: rail
- **type**: humanist
- **motion**: drift
- **media**: editorial-collage
- **composition**: minimal-sequence
- **spacing**: balanced
- **shape**: soft
- **pageLayout**: split
- **footer**: deep-grid
